# Квалитет — стоматологическая клиника

Проект подготовлен для статической публикации на GitHub Pages.

## Локальная разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовый статический сайт появится в папке `dist/`.

## Публикация на GitHub Pages

1. Загрузите содержимое репозитория в GitHub (включая `.github/workflows/deploy.yml`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main`. GitHub Actions автоматически соберёт и опубликует сайт.

Сборка автоматически учитывает имя репозитория как base path, поэтому проектные GitHub Pages вида `https://username.github.io/repository/` получают правильные ссылки на Next.js-ресурсы и изображения.

## Ограничения GitHub Pages

GitHub Pages — статический хостинг и не запускает серверные API, базы данных или обработчики Next.js. API-маршруты исключены из статической версии. Форма записи сохраняет демо-заявку в браузере пользователя (localStorage); она не отправляет заявку в клинику. Административная панель, требующая API, не является рабочей CMS в GitHub Pages. Для реального приёма заявок и управления контентом понадобится отдельный backend или внешний сервис форм.
